
# Currículum Vitae | Mauricio Iván López Holguín

Sitio web personal desarrollado con HTML5 y CSS3 para presentar mi perfil profesional, experiencia, formación académica, certificaciones y habilidades técnicas.

Este proyecto fue realizado como parte de la materia **Programación para Plataformas Emergentes** de la Universidad Autónoma de Chihuahua (UACH).

## Objetivo

Desarrollar un currículum vitae digital mediante tecnologías web, aplicando HTML semántico, hojas de estilo CSS y diseño responsivo para ofrecer una presentación moderna, profesional y accesible desde diferentes dispositivos.

## Tecnologías utilizadas

- **HTML5:** Estructura y organización del contenido.
- **CSS3:** Diseño visual, colores, tipografía y efectos.
- **CSS Grid y Flexbox:** Distribución de elementos.
- **Media Queries:** Adaptación a dispositivos móviles.
- **Git y GitHub:** Control de versiones y almacenamiento del proyecto.
- **GitHub Pages:** Publicación del sitio web.

## Características

- Diseño moderno con colores azul oscuro y cyan.
- Interfaz organizada en dos columnas.
- Diseño responsivo para computadoras, tablets y celulares.
- Enlaces interactivos de contacto.
- Secciones de experiencia, educación y certificaciones.
- Efectos visuales y transiciones CSS.
- Estilos adaptados para impresión en PDF.

## Estructura del proyecto

```text
curriculum-vitae/

```

## Contenido del currículum

1. Título
2. Datos personales.
3. Perfil y objetivo profesional.
4. Experiencia profesional.
5. Preparación académica.
6. Idiomas.
7. Habilidades técnicas.
8. Certificaciones.

## Ejecución local

No es necesario instalar dependencias adicionales.

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador web.

## Publicación

El proyecto está preparado para publicarse gratuitamente mediante **GitHub Pages**, utilizando la rama principal del repositorio.
